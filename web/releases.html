Latest stable release

Reviewed release: WizeStream 1.50.0 (22 November 2026). Guides also cover merged source reviewed 23 November 2026. Changes marked after 1.50.0 need a build containing them. Check release availability ↗

Merged after 1.50.0.

  • Manual code pairing for devices without a camera, pairing/setup log events and a performance-diagnostics switch in release-build sync settings.
  • Ongoing non-Default profile history journaling and local-only profile removal.
  • Vimeo public playback, collections and events, with optional public API search and comments.
  • Saved offline chapters and transcripts, supported embedded local chapters, and optional artwork in new MP3/M4A downloads.
  • Return to previous playback, remaining-time estimates, and further caption/player/interface controls.

These changes are present in the reviewed source snapshot and require a build containing them. They are not in the 1.50.0 APK; open pull requests are outside this snapshot. Recent Home memory and Device Sync changes do not establish that every reported failure is resolved.
