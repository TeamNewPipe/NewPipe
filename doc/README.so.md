## Ogeysiis muhiim ah oo ku saabsan fork-ga

NewPipe Material waa fork madax-bannaan oo laga sameeyay NewPipe, wuxuuna diiradda saaraa naqshadda Material 3, theme-yada app-ka, iyo hagaajinta muuqaalka iyo khibradda isticmaalka.

Mashruucan **lama xiriiro, lama kafaalo qaaday, mana ansixin** mashruuca rasmiga ah ee NewPipe, TeamNewPipe, ama NewPipe e.V.

NewPipe Material wuxuu ku dhisan yahay NewPipe wuxuuna ilaaliyaa ruqsadda software-ka xorta ah ee NewPipe, credits-ka upstream, iyo ogeysiisyada ruqsadaha dhinacyada saddexaad.

---

## Waa maxay NewPipe Material?

NewPipe Material wuxuu ilaaliyaa khibradda aasaasiga ah ee NewPipe isagoo casriyeynaya aqoonsiga app-ka iyo interface-ka isticmaale.

Ujeeddooyinka fork-gan:

- Surfaces, dialogs, settings, tabs, iyo navigation laga soo dheegtay Material 3
- Taageerada Material You dynamic colors marka la heli karo
- Theme color presets gacanta lagu doorto: App default, Neutral, Green, Blue, Purple, Orange, Pink, iyo Red
- Aqoonsi app cusub: **NewPipe Material**
- Application ID gaar ah: `org.wisso.newpipematerial`
- Debug builds waxay si gaar ah ugu rakibmaan `org.wisso.newpipematerial.debug`
- Ilaalinta dhaqanka NewPipe, import/export compatibility, iyo services-ka la taageero

Fork-gani wuxuu ka fogaadaa beddelka khatarta leh ee meelaha xasaasiga ah sida playback, downloads, background playback, popup playback, iyo Extractor logic, ilaa isbeddelladaas loo sameeyo si gaar ah oo la tijaabiyay.

## Features

NewPipe Material wuxuu hayaa features-ka la yaqaan ee NewPipe: daawashada videos iyo live streams, background playback, popup player, local playlists, subscriptions aan platform account u baahnayn, channel groups, search, video details, downloads, iyo data import/export.

Waxyaabaha Material lagu daray waxaa ka mid ah Material 3 color roles, bottom navigation marka tabs-ku yihiin shan ama ka yar, dynamic/manual Theme colors, fork attribution ee About screen, iyo release signing support.

## Installation

Ku rakib NewPipe Material GitHub Releases ee repository-kan ama signed artifacts marka la heli karo.

```text
Official NewPipe: org.schabi.newpipe / net.newpipe.app iyadoo ku xiran upstream build
NewPipe Material: org.wisso.newpipematerial
Debug:            org.wisso.newpipematerial.debug
```

Si aad xogta u wareejiso, database-ka ka export garee official NewPipe adigoo isticmaalaya Settings > Backup and Restore, rakib NewPipe Material, kadib import garee backup-ka. Had iyo jeer backup hayso.

Ha ku daabicin NewPipe Material, NewPipe, ama NewPipe forks Google Play.

---

## Build from source

Requirements: JDK 21, Android SDK, iyo Gradle wrapper-ka repository-ga.

```bash
./gradlew runCheckstyle -DskipFormatKtlint
./gradlew assembleDebug lintDebug testDebugUnitTest --stacktrace -DskipFormatKtlint
./gradlew assembleDebug -DskipFormatKtlint
```

Debug build wuxuu isticmaalaa magaca **NewPipe Material Debug** iyo package-ka `org.wisso.newpipematerial.debug`.

## Development status

Completed ama in progress: app name iyo ID, debug/release identity separation, Material 3 colors, dynamic/manual colors, bottom navigation, About screen, dialogs, snackbars, settings, video detail, download UI, iyo signing workflow.

Deferred ama high-risk: main player overlay, seekbar/gesture colors, queue controls, quality/audio/caption menus, iyo broad playback/download behavior changes.
