## NewPipe Material ਕੀ ਹੈ?

NewPipe Material, NewPipe ਦਾ core experience ਕਾਇਮ ਰੱਖਦਾ ਹੈ ਅਤੇ app identity ਤੇ user interface ਨੂੰ modern ਬਣਾਉਂਦਾ ਹੈ।

Fork ਦੇ ਟੀਚੇ:

- Material 3 inspired surfaces, dialogs, settings, tabs ਅਤੇ navigation
- ਉਪਲਬਧ ਹੋਣ ਤੇ Material You dynamic colors
- manual Theme color presets: App default, Neutral, Green, Blue, Purple, Orange, Pink ਅਤੇ Red
- ਨਵਾਂ app identity: **NewPipe Material**
- ਵੱਖਰਾ application ID: `org.wisso.newpipematerial`
- debug builds ਵੱਖਰੇ ਤੌਰ ਤੇ `org.wisso.newpipematerial.debug` ਵਜੋਂ install ਹੁੰਦੇ ਹਨ
- NewPipe behavior, import/export compatibility ਅਤੇ supported services ਕਾਇਮ ਰਹਿੰਦੇ ਹਨ

ਇਹ fork playback, downloads, background playback, popup playback ਅਤੇ Extractor logic ਵਰਗੇ sensitive areas ਵਿੱਚ risky behavior changes ਤੋਂ ਬਚਦਾ ਹੈ, ਜਦ ਤਕ ਉਹ dedicated ਅਤੇ tested changes ਨਾ ਹੋਣ।

## Installation

NewPipe Material ਨੂੰ ਇਸ repository ਦੀਆਂ GitHub releases ਜਾਂ signed artifacts ਤੋਂ install ਕਰੋ।

```text
Official NewPipe: org.schabi.newpipe / net.newpipe.app upstream build ਅਨੁਸਾਰ
NewPipe Material: org.wisso.newpipematerial
Debug:            org.wisso.newpipematerial.debug
```

Data migrate ਕਰਨ ਲਈ official NewPipe ਤੋਂ Settings > Backup and Restore ਵਿੱਚ database export ਕਰੋ, NewPipe Material install ਕਰੋ ਅਤੇ backup import ਕਰੋ। ਹਮੇਸ਼ਾ backup ਰੱਖੋ।

NewPipe Material, NewPipe ਜਾਂ NewPipe forks ਨੂੰ Google Play ਤੇ publish ਨਾ ਕਰੋ।

## Source ਤੋਂ build ਕਰੋ

Requirements: JDK 21, Android SDK ਅਤੇ repository ਦਾ Gradle wrapper।

```bash
./gradlew runCheckstyle -DskipFormatKtlint
./gradlew assembleDebug lintDebug testDebugUnitTest --stacktrace -DskipFormatKtlint
./gradlew assembleDebug -DskipFormatKtlint
```

Debug build **NewPipe Material Debug** ਨਾਮ ਅਤੇ `org.wisso.newpipematerial.debug` package ਵਰਤਦਾ ਹੈ।
